# pagila-hw [![](https://github.com/shmoles/pagila-hw/actions/workflows/tests.yml/badge.svg)](https://github.com/shmoles/pagila-hw/actions?query=workflow%3Atests)

SQL homework using the Pagila PostgreSQL sample database.

This repo contains solutions to the queries in the `sql/` folder, along with a fixed GitHub Actions workflow that runs the test suite.

## Notes

- SQL solutions are in `sql/`
- Tests run with `./run_tests.sh` inside the database container
- GitHub Actions badge above reflects this fork
